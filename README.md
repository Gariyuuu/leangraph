# LeanGraph

Verifier-guided LLM agents for formal mathematics in Lean 4. LeanGraph measures how often a language model
writes a proof that **Lean accepts**, and whether retrieval of Mathlib lemmas, a planning step and repair from
compiler errors raise that rate. Plausible text scores zero; only a certified proof counts.

## What counts as a proof

A proof is verified only when a fresh `lean` process, pinned to Lean 4.33.1 and Mathlib v4.33.1, compiles it with
no errors or `sorry`; it depends on no axiom beyond `propext`, `Classical.choice`, `Quot.sound`; the file adds no
declaration besides the target; and, for a theorem taken from Mathlib, the proof uses nothing from that theorem's
module or any module built on it. The certifier reports under a random per-run nonce, so model-written text cannot
forge its verdict. See `leangraph/verify.py` and `tests/test_verify_lean.py` (attacks tested with the text filter
disabled).

## Model and scope

One model: the owner's OpenAI-compatible gateway (`api.gariyuuu.com`), whose documentation names the upstream as
Qwen3-8B; the upstream was not verified independently. Reasoning is off (`/no_think`), replies are capped at 2,048
tokens, and the gateway allows 60 requests per minute per key. By the owner's decision there is no reasoning-on tier
and no second model, so research question 6 (can cheaper inference with strong scaffolding compete with more
expensive inference?) is not answered. Repeated draws of the same request turned out to be nearly deterministic at
this gateway, so resampled drafts carry fixed seeds; see `docs/DECISIONS.md` (2026-09-11).

## Benchmark

203 theorems in `corpus/tasks.jsonl`:

* **Mathlib held-out** (150: 121 test, 29 dev). Sampled from near-leaf modules of Mathlib's import graph
  (≤ 20 dependents, none a tactic module). The target's module and everything downstream are banned from the
  proof and from the retrieval index. Statements are Lean's own signatures, each round-tripped through Lean.
* **Authored** (53). Written for this project; every reference proof is certified (`corpus/novel_verified.jsonl`).

Families: algebra, inequalities, sets, functions, number theory, probability, category theory.

## Layout

```
leangraph/verify.py      two-tier verifier: REPL for search, fresh-process certifier as judge
leangraph/agent.py       one loop; every baseline and ablation is a configuration of it
leangraph/retrieval.py   BM25 (sparse matrix), dense (bge-small), hybrid (RRF) over 260,003 user-facing Mathlib
                         theorems (the 262,216-theorem dump minus 2,213 tactic-implementation lemmas)
leangraph/corpus.py      import graph, held-out module selection, candidate pool
leangraph/build.py       Lean-side filtering, round-trip, balanced selection, authored-proof certification
leangraph/run.py         runs configurations over tasks; resumable JSONL traces
leangraph/errors.py      error taxonomy from Lean messages (+ 473,141-name table for namespace errors)
leangraph/analyze.py     metrics, paired McNemar tests with Holm correction, taxonomy, cost
leangraph/figures.py     paper figures (validated palette) with CSV table twins
leangraph/paper.py       paper generated from frozen results; directional claims gated on Holm p < 0.05
leangraph/export_site.py static JSON for the web app in site/
lean_env/                pinned Lean project (Mathlib) + the Lean scripts that dump the corpus
site/                    Next.js app: overview, leaderboard, theorems, traces, retrieval, repair, errors, cost, methods, paper
```

## Reproduce

```
make setup            # elan, Lean 4.33.1, Mathlib cache, Lean REPL, Python venv
make corpus           # premise dump, candidates, Lean metadata, verified task list
make benchmark-smoke  # three theorems through template, direct, repair and BM25 retrieval + repair
make retrieve         # retrieval benchmark
make prove            # every configuration on the test split (or, resumable and gateway-aware:
                      #   bash scripts/run_main_grid.sh >> results/main_grid.log 2>&1)
make analyze figures paper site
make test             # fast tests;  make test-lean for the Lean-backed verifier tests
make reproduce        # recompute everything from cached model responses, no API calls
```
